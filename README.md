# 股票損益管家（Stock Tracker）

個人股票交易損益紀錄 Web App，不需要帳號、後端或外部套件。

## 功能
- 新增、修改、刪除交易紀錄
- 股票代號或名稱、交易日期、賺錢／賠錢／持平及金額
- 日期起迄與股票名稱搜尋，清單和所有統計同步變動
- 賺錢總額、賠錢總額、淨損益、總筆數、賺錢筆數、賠錢筆數、持平筆數、勝率
- 勝率 = 賺錢筆數 / 篩選後總筆數 × 100%
- 匯出篩選清單 CSV、備份及匯入完整 JSON
- 資料保存在瀏覽器 localStorage，不會自動跨裝置同步

## 開始使用
下載或 Clone 此 Repository，使用瀏覽器開啟 index.html 即可。

## 注意
- 賺錢或賠錢的金額皆輸入大於 0 的整數，系統依類型計算符號。
- 持平（0元）計入總筆數及勝率分母，但不算賺錢或賠錢。
- 更換裝置、瀏覽器或清除網站資料可能遺失紀錄，建議定期備份 JSON。
- 本工具只用於個人記帳，不提供投資建議。
